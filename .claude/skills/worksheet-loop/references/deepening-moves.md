# 問いを深める手筋

同じ内容でも、問い方を変えると生徒の思考は変わる。
作問・差し替えのときは、必ずどの手筋を使ったか名前で記録する。

---

## M1 逆向きにする
結論を与えて条件を問う。

- 浅い: 「AB＝AC のとき ∠B を求めよ」
- 深い: 「∠B＝∠C である三角形は、かならず二等辺三角形といえるか」
- 深い: 「△ABD ≡ △ACE を示すには、あと何が分かればよいか。考えられるものを全部あげよ」

## M2 条件を1つ外す
成り立たなくなるかを確かめさせる。反例づくりが生まれる。

- 浅い: 「平行四辺形の対角線はそれぞれの中点で交わる」を証明せよ
- 深い: 「対角線が中点で交わる四角形は平行四辺形か。平行の条件を使わずに説明できるか」
- 深い: 「AB∥DC かつ AD＝BC だけでは平行四辺形といえない。図をかいて示せ」

## M3 誤答を提示する
他人の答案を直させる。採点ではなく「どこから違ったか」を言わせる。

- 「次の証明には1か所まちがいがある。どの行か。なぜそこがまちがいか」
- 「この生徒は『仮定より ∠B＝∠C』と書いた。なぜこれが使えないのか」

## M4 複数解法を比べる
解けるかではなく、使い分けを問う。

- 「この問題は、二等辺三角形の性質を使う方法と、合同を使う方法の両方で解ける。
  どちらが短いか。図が変わったらどちらが使えなくなるか」

## M5 一般化を問う
1つの例から「いつでも言えるか」へ。

- 浅い: 「∠A＝48° のとき ∠B を求めよ」
- 深い: 「∠A＝a° のとき ∠B を a で表せ。a はどこまで大きくできるか」

## M6 定義に戻らせる
使った根拠が「なぜ使えるのか」を問う。

- 「『底角が等しい』を根拠に使ったが、それはどこで証明したことか」
- 「平行四辺形の定義は何か。性質と定義のちがいを説明せよ」

## M7 条件を動かす
条件を変えると結論がどう動くかを追わせる。

- 「点 D を B に近づけていくと、AD の長さと ∠ADB はどう変わるか」
- 「平行四辺形に AC＝BD を加えると長方形になる。では AC⊥BD を加えると何になるか。
  両方を加えると何になるか」

## M8 つくらせる
条件を満たす図・式・問題を生徒がつくる。正解が1つでなくなる。

- 「対角線が垂直に交わるが、平行四辺形ではない四角形をかけ」
- 「△ABD ≡ △ACE となる図を、BD＝CE を使わずに自分で設定してかけ」
- 「この定理を使う問題を1つ自分でつくり、となりの人に解いてもらえ」

---

## 使い方の目安

| 症状 | 当てる手筋 |
|---|---|
| 穴うめばかりで作業になっている | M1 / M3 |
| 正しく書けるが考えていない | M2 / M6 |
| 速い生徒が退屈している | M5 / M7 / M8 |
| 誤答が起きない（情報が出ない） | M3 / M2 |
| 本時の知識だけで閉じている | M6 / M4 |
| 答え合わせで終わる | M7 / M8 |

## 注意

- 1枚に手筋を詰め込まない。1時間なら深い問いは **1〜2問**。残りは足場。
- M8（つくらせる）は時間を食う。時間配分を先に決める。
- 深くするために問題文を長くしない。読み落としが増えるだけで思考は深まらない。
